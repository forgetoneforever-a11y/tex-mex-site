# TEX-MEX SITE 📅

Веб-сайт календаря-расписания с glassmorphism дизайном и AI Ассистентом

## Функции

- 📅 **Календарь** с заметками
- 📚 **Расписание пар** по дням недели
- 📝 **Домашние задания** с отметками выполнения
- 📌 **Заметки** к датам с приоритетами и медиа (фото/видео)
- 🤖 **AI Ассистент** - умный чат-бот для помощи с учёбой

## Установка

1. Клонируй репозиторий
2. Установи зависимости:
   ```
   npm install
   ```
3. Создай `.env` файл:
   ```
   PORT=3000
   OPENAI_API_KEY=твой_ключ_openai
   ```
4. Запусти сервер:
   ```
   npm start
   ```

Открой сайт: http://localhost:3000

## Деплой на Render

1. Создай Web Service на Render
2. Подключи GitHub репозиторий
3. Добавь environment variable `OPENAI_API_KEY`
4. Render автоматически запустит `npm start`

## Технологии

- Node.js + Express
- SQLite3
- OpenAI API
- Glassmorphism UI
- Multer (загрузка файлов)

## AI Ассистент

Встроенный AI чат-бот помогает:
- Планировать расписание
- Организовывать домашние задания
- Давать советы по учёбе
- Отвечать на вопросы
